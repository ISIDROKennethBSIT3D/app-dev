# My Favorite Movie: Kung Fu Hustle
**Kung Fu Hustle** is a 2004 martial arts action-comedy film directed, produced, and starred in by *Stephen Chow*. Set in 1940s Shanghai, it follows a wannabe gangster named Sing who tries to join the notorious Axe Gang, only to stumble upon a slum housing hidden kung fu masters.
